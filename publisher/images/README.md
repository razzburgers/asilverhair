# Custom article images

Every post automatically receives a generated 1600x900 silver editorial cover.

To replace one, upload a JPG/JPEG/PNG/WEBP/SVG here, then set that entry's `image` field in `publisher/entries.json` to the filename. Optionally update `image_alt`.

The custom image becomes the article hero, Open Graph/X preview, and BlogPosting image. If missing or invalid, the generated cover is used.

Recommended: 1600x900 or larger, landscape.
