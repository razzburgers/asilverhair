ASilverHair — GitHub Pages Release

Repository root should contain these files/folders directly:
  index.html
  about.html
  404.html
  CNAME
  robots.txt
  sitemap.xml
  rss.xml
  entries.json
  assets/
  entries/

CNAME is already set to:
  asilverhair.com

GitHub Pages setup:
1. Create a GitHub repository, for example: asilverhair
2. Upload the CONTENTS of this ZIP to the repository root.
3. Repository Settings -> Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: /(root).
6. Save.
7. In Custom domain, enter: asilverhair.com
8. Configure DNS at your registrar for GitHub Pages.
9. After GitHub validates the domain/certificate, enable Enforce HTTPS.
10. Submit https://asilverhair.com/sitemap.xml to Google Search Console.

This package contains no PebbleHost server.js, no port 8171 configuration,
and no dependency on the CabinetClub/ActivityShell infrastructure.
